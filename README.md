📖 Sobre o Projeto

Este é um site informativo criado para ajudar pessoas a planejarem e organizarem sua rotina de cuidados com a pele (skincare). Ele apresenta dicas, orientações e estrutura de rotina para tornar o autocuidado mais simples e eficaz.

🚀 Tecnologias Utilizadas

HTML5 — Estrutura das páginas.

CSS3 — Estilização, layout e responsividade.

JavaScript — Para interações leves ou futuras funcionalidades.

GitHub Pages — Hospedagem do site diretamente do repositório GitHub.

🛠️ Funcionalidades Principais

Seção para descrever etapas da rotina de skincare.

Campo de busca para facilitar a navegação no conteúdo.

Design responsivo para uso em diferentes dispositivos.
